Visual encodings (how humans read the model):
• Color: predicted class (see legend).
• Size: larger markers = higher uncertainty → the model is unsure.
• Opacity: more opaque = more diverse → different from what’s already labeled.
• Shape from novelty: ◯ high, □ medium, ✕ low.
• Red borders: class coverage pressure (K highest).
• Black borders: local density pressure (K highest).
• Purple borders: where coverage and density both demand attention.

Instead of labeling random suggestions, the annotator can choose which trade-offs to prioritize and shape the model’s learning path.
